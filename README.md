## 🚀 概要 (Overview)

**ENOKIOSK SYSTEM** は、店舗のデジタルサイネージや公共・専用端末の **KIOSKモード** での自動起動・常時稼働に特化した、サイバーパンクデザインのハイテク情報ダッシュボードです。  
マウスカーソルを完全に非表示化し、テキスト選択を無効化することで、専用端末として洗練された没入感のあるUIを提供します。

---

## ✨ 主な機能 (Key Features)

- **🚗 関東の交通情報 (JARTIC連携)**
  - 高速道路などの通行止や車線規制情報をリアルタイム表示。
  - 警告度に応じたハイライト表示（通行止は赤色点滅、車線規制は琥珀色）。
  - 10分周期で外部PHPから自動更新。
- **🌤️ 地域別天気予報 (東京・埼玉・千葉)**
  - 東京・埼玉・千葉の現在の気温、降水量、翌日の天気をカード形式で表示。
  - 10秒ごとに地域を自動巡回して詳細な「天気概況」を切り替え表示。
  - 専用のプログレスバーによる視覚的な切替カウントダウン。
- **📰 ニュース速報カルーセル (上下2件分割)**
  - ニュース情報を上下50%ずつに分けて2件同時に表示。
  - 16秒ごとにスムーズに次のニュースへスライド進行。
  - 全件の流し終わりに自動で最新情報を再取得。
- **🕒 リアルタイムHUDクロック & Kiosk最適化**
  - ゼロカーソル (`cursor: none`) とテキスト選択禁止による完全なKiosk制御。
  - サイバーパンク調の走査線（スキャンライン）とSFグリッド背景。

## 🛠️ システム構成と外部連携 (API Specifications)

本システムは、以下の外部PHPエンドポイントからJSONデータを受け取り、自動更新を行います。サーバー側で以下の形式のJSONを返却するスクリプトをご用意ください。

### 1. 交通情報: `./getJartic.php`

```json
{
  "time": "2026年10月23日 01時12分時点での関東の交通情報",
  "datas": ["【都心環状線】（内回） 新富町出口で工事のため、通行止"]
}
```

### 2. 天気情報: `./getWeather.php`

```json
{
  "取得日": "2026年10月23日 01時16分",
  "datas": {
    "東京": {
      "現在の気温": "14.9 度",
      "現在の降水量(10分あたり)": "0 mm",
      "翌日の天気": "晴れ 朝晩 くもり",
      "天気概況": "関東甲信地方は..."
    },
    "埼玉": { ... },
    "千葉": { ... }
  }
}
```

### 3. ニュース情報: `./getNews.php`

```json
[
  {
    "title": "ニュースタイトル",
    "description": "ニュースの概要説明..."
  }
]
```

## ⚙️ インストール・導入方法 (Installation)

1. リポジトリをクローン、またはファイルをWebサーバーのドキュメントルートに配置します。

   ```bash
   git clone https://github.com/jikantoki/enokiosk.git
   ```

1. ロゴ画像（enokiosk.jpg）がルートディレクトリに配置されていることを確認します。

1. PHPが実行可能な環境（Apache / Nginx等）でホストし、必要に応じて各PHPスクリプトを連動させてください。
   - ※PHP環境がない場合やオフライン環境では、自動的に内蔵モックデータで動作します。
